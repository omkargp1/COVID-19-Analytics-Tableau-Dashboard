# 📊 COVID-19 Analytics Dashboard

An interactive Tableau dashboard designed to transform complex pandemic data into clear, actionable visual insights. This project enables users to analyze confirmed cases, active cases, deaths, recoveries, and regional trends through an intuitive, data-driven visual reporting experience.

---

## 📌 Overview

* **Author:** Omkar Pardeshi
* **Tech Stack:** Tableau
* **Project Type:** Open Source
* **Duration:** 4 Days
* **Impact:** Reached 30+ users in 30 days

---

## 🚀 The Challenge

COVID-19 data is complex, fast-moving, and difficult to interpret when presented only in raw tables. Tracking case counts, death rates, recovery trends, and regional comparisons can quickly become overwhelming without clear visual structure.

The goal of this project was to simplify complex public health data, helping users easily understand the global and regional impact of the pandemic through a visual story highlighting key patterns and indicators.

---

## 🛠️ Solution & Technical Implementation

The dashboard was built in Tableau with a focus on clean visualization, interactive analysis, and rapid interpretation of pandemic trends.

### 1. Key Public Health Metrics & Regional Impact
* Applied calculated fields and visual aggregations to convert raw pandemic records into clear KPIs (Total Cases, Deaths, Recoveries, Active Cases).
* Consolidated core indicators into a unified reporting layout to visualize overall infection spread and mortality impact.

### 2. Interactive Features & Data Exploration
* Integrated interactive geographic filters and regional comparisons allowing users to explore pandemic spread across different locations.
* Built custom visual breakdowns enabling users to drill down into high case concentration areas and identify regional variations.

### 3. Visual Storytelling & Layout Design
Structured the dashboard workflow from **High-Level Indicators to Detailed Insights**:
* **Top Level:** KPI cards for executive-level status checks.
* **Deep-Dive Level:** Supporting charts and maps explaining regional severity and trend patterns.
